# 证据决策简报验收记录

验收日期：2026-07-24

## 自动化验收

- 服务层覆盖企业简报结构、来源与证据链引用、限制和禁止推断。
- API 覆盖企业列表、已知企业简报、未知企业 `404` 和能力标志。
- 前端覆盖第六个竞赛导航入口、企业选择、加载/错误/空状态、打印样式和移动端布局规则。
- 静态页面由 `webapp/frontend_src/build.py` 生成。

## 浏览器验收

- 桌面端本地页面 `http://127.0.0.1:8010/` 正常加载，无空白页。
- “证据决策简报”导航入口唯一且可进入。
- 11 个简报章节、来源引用、证据链、风险限制和禁止推断均可见。
- 企业选择器可从阿斯利康切换至恒瑞医药并刷新简报内容。
- 当前浏览器控制接口不提供视口调整能力；移动端未声称完成真实设备验收，由移动端前端自动化断言覆盖。

## 边界

- 打印/PDF 按钮仅调用浏览器打印能力，不在自动化中实际保存文件。
- 来源按钮进入现有证据中心，不修改来源登记表或事实配置。
- 简报仅归纳当前人工核验样本，不输出疗效、成功率、企业排名或投资建议。
