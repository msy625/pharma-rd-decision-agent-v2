# 药研罗盘

药研罗盘是一个以规范化公开证据为基础的医药研发信息浏览与决策支持网站。它将临床试验、论文、监管资料和机构公开信息组织成可检索、可关联并可回到原始来源的记录，帮助使用者查看研究进展、证据覆盖与资料缺口。当前数据覆盖多个疾病研究方向，并非以单一疾病为核心。

[在线体验](https://pharma-rd-decision-agent.onrender.com/)

## 当前数据

网站运行数据来自 `data/template/` 中的规范化 CSV/JSON 表；`data/source_registry.csv` 等旧文件仅用于历史兼容，不是当前网站的主数据入口。当前数据清单见 [`data/template/data_manifest.json`](data/template/data_manifest.json)，它记录网站数据版本和各表条数。

截至仓库数据清单日期（2026-09-28），数据包括：

| 数据对象 | 条数 |
| --- | ---: |
| 机构 | 43 |
| 来源 | 1,047 |
| 研究 | 643 |
| 论文 | 402 |
| 研究领域目录 | 27 |
| 规范化关系 | 3,692 |

目录包含 6 个研发阶段及 20 个疾病研究方向。上述数量是数据表记录数，不代表行业覆盖率、机构实力、疗效或研发成功率。来源须满足有效链接、核验状态及明确关系等网站准入条件；进入网站的数据统一按已确认来源口径展示，不区分人工整理或机器采集。

## 网站功能

- **研发决策总览**：查看数据概况、代表性机构样例，以及可折叠的研究领域和研究状态。
- **机构研发画像**：查看单个机构在当前数据集中的研究、来源与证据链覆盖；仅反映已收录样本。
- **研发事件时间轴**：按事件类型浏览研究开始/完成、论文发表和监管事件等日期。未来研究日期可能表示计划日期；尚待核验的未来论文日期会作提示，不能理解为已发生事件。
- **研发证据中心**：检索来源、查看证据链、比较机构，并浏览研究方向资料。
- **智能研发决策 Agent**：提交问题后选择“本地证据分析”或可用的智能生成模式；问题提交后才生成回答。回答以直接结论为主，关键数据可展开查看，引用可回到来源。
- **证据决策简报**：按机构或研究方向整理结构化证据摘要。

网站还提供数据底座/规范化数据浏览等辅助入口。试验、论文与监管资料按各自实体及明确关系展示；相似名称本身不会自动建立关联。监管资料统一称为“监管链”，其数量与临床研究证据链分别理解。

## 技术结构

```text
浏览器静态前端
       ↓ HTTP API
FastAPI 应用与领域服务
       ↓
data/template/ 规范化数据
       ↓（可选）
配置的大语言模型服务
```

- 后端：Python、FastAPI、Uvicorn。
- 前端资源：`webapp/frontend_src/` 与 `webapp/static/`。
- 轻量运行依赖：`requirements-deploy.txt`。
- 常用状态接口：`/health`、`/ready`、`/api/runtime-capabilities`。
- `/ready` 用于检查应用数据是否可读取；部署是否更新还应结合部署记录和实际页面/API 响应判断。

Agent 的本地证据分析不要求模型密钥。配置了模型服务且功能启用时，智能生成模式可请求模型；模型未配置或调用不可用时，应以本地证据能力为准。模型输出不能替代来源核对，也不应将证据数量解释为疗效或成功概率。

## 本地启动（Ubuntu / WSL）

在仓库根目录执行。优先使用已有虚拟环境；如依赖尚未安装，可在项目环境中安装轻量运行依赖：

```bash
python -m pip install -r requirements-deploy.txt
```

启动网站：

```bash
.venv/bin/python -m uvicorn webapp.main:app --host 127.0.0.1 --port 8000
```

若已激活项目虚拟环境，也可将命令中的 `.venv/bin/python` 换为 `python`。浏览器访问 <http://127.0.0.1:8000/>；在终端按 `Ctrl+C` 停止。

### 可选模型配置

仅在需要使用智能生成模式时配置模型密钥。复制示例文件并在本机填写 `.env`：

```bash
cp .env.example .env
```

不要将真实密钥写入代码或提交到 Git。使用 `.env` 启动：

```bash
.venv/bin/python -m uvicorn webapp.main:app --host 127.0.0.1 --port 8000 --env-file .env
```

具体模型提供方、模型名称及开关以 `.env.example` 和部署环境配置为准。

## 部署说明

仓库提供 Render 配置 `render.yaml`。当前配置使用轻量依赖并启动 `webapp.main:app`；其中 `autoDeploy: false`，因此仅推送 Git 不会自动更新线上站点，需要在 Render 控制台触发部署。线上版本是否更新，应以 Render 部署记录和线上页面/API 为准；本地文件或 Git 推送成功本身不代表线上已部署。

## 数据与使用边界

- 来源记录保留来源编号和原始链接，展示数据应能回查对应资料。
- 研究状态、资料核验状态和事件日期是不同字段，不应混为一谈。
- 当前机构画像和机构比较只描述本数据集的收录情况，不代表机构全貌或优劣。
- 系统用于公开资料整理、研究与决策支持，不提供医疗诊断、治疗建议、跨试验疗效排名、成功率预测或投资建议。
- 外部来源的版权和使用条款归来源方所有；应以监管机构、试验注册平台、论文原文及机构正式公告为准。
